## 💻 Usage

### 🔮 Making Predictions

```python
import pickle
import numpy as np

# Load the trained model
with open('diabetes_model.pkl', 'rb') as f:
    model = pickle.load(f)

# Load the scaler
with open('scaler.pkl', 'rb') as f:
    scaler = pickle.load(f)

# Patient data: [Pregnancies, Glucose, BP, Skin, Insulin, BMI, DPF, Age]
patient_data = np.array([[6, 148, 72, 35, 0, 33.6, 0.627, 50]])

# Scale the data
patient_data_scaled = scaler.transform(patient_data)

# Make prediction
prediction = model.predict(patient_data_scaled)
probability = model.predict_proba(patient_data_scaled)[0][1]

print(f"Prediction: {'Diabetes' if prediction[0] == 1 else 'No Diabetes'}")
print(f"Probability: {probability:.2%}")
```

## 🤔 Interview Questions

### 1️⃣ What is the difference between precision and recall?

**Answer:**

- **Precision**: Out of all predicted positive cases, how many are actually positive?
  ```
  Precision = True Positives / (True Positives + False Positives)
  ```
  - High precision = Few false alarms
  - Important when cost of false positive is high

- **Recall (Sensitivity)**: Out of all actual positive cases, how many did we correctly identify?
  ```
  Recall = True Positives / (True Positives + False Negatives)
  ```
  - High recall = Few missed cases
  - Important in medical diagnosis (don't miss diabetes cases)

**Trade-off**: In diabetes prediction, we prioritize **recall** to avoid missing actual diabetes cases, even if it means some false positives.

### 2️⃣ What is cross-validation, and why is it important in binary classification?

**Answer:**

**Cross-Validation** is a technique to assess model performance by:
1. Splitting data into k equal folds
2. Training on k-1 folds, testing on remaining fold
3. Repeating k times with different test fold
4. Averaging results

**Importance in Binary Classification:**
- ✅ **Reduces overfitting**: Tests on unseen data multiple times
- ✅ **Better performance estimate**: More reliable than single train-test split
- ✅ **Handles imbalanced data**: Ensures all classes represented in each fold
- ✅ **Model selection**: Compares different models objectively
- ✅ **Hyperparameter tuning**: Finds optimal parameters

**Our Implementation**: 5-Fold CV with stratification to maintain class balance
